# CarePaws 🐾

CarePaws is a pet healthcare and wellness application built with Flutter. The app helps pet owners connect with veterinarians, book consultations, manage appointments, and access pet care services through a simple and user-friendly interface.

## Features

- Online Doctor Consultation
- Appointment Booking
- Doctor Profiles
- Pet Care Services
- Community Section
- User Profile Management
- Responsive Flutter UI
- Clean and Reusable Architecture
- Navigation and Route Management

## Tech Stack

- Flutter
- Dart
- REST APIs
- Git & GitHub
- Android Studio
